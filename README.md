# DEV.F-EXT_FRONTEND-Modulo1_Introduccion-a-JavaScript

Reto de la clase "Introduccion a JavaScript" del Master de desarrollo Web con IA de DEV.F

## Descripcion del Proyecto

Este repositorio contiene los ejercicios y practicas del **Modulo 1: Introduccion a JavaScript** del programa de DEV.F. El objetivo es practicar los conceptos basicos de JavaScript, incluyendo tipos de datos, variables, operadores y estructuras fundamentales del lenguaje.

## Contenido

| Archivo | Descripcion |
|---------|-------------|
| `tipos-de-dato.js` | Ejercicios sobre los distintos tipos de datos en JavaScript usando `typeof` |
| `variables-y-operadores.js` | Practica con declaracion de variables y operadores basicos |

## Como ejecutar los archivos

Para ejecutar cualquiera de los archivos JavaScript, usa Node.js desde la terminal:

```bash
node tipos-de-dato.js
node variables-y-operadores.js
```

O bien, puedes incluirlos en un archivo HTML y ver los resultados en la consola del navegador.

## Tecnologias

- JavaScript (ES6+)
- Node.js (para ejecucion en terminal)
